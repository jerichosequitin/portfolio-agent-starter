# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository:

`https://github.com/jerichosequitin/portfolio-agent-starter/security/advisories/new`

Include the affected revision, reproduction steps, expected impact, and any safe
proof of concept. Do not include real credentials, private conversations, or data
that belongs to another person.

Maintainers will acknowledge a complete report when available, investigate it, and
coordinate a fix and disclosure based on severity. No fixed response or remediation
timeline is promised.

## Supported versions

Security fixes target the latest revision on the default branch. This starter does
not maintain a backport schedule. Owners of deployed copies are responsible for
tracking upstream changes, protecting provider credentials, configuring rate limits,
and reviewing their hosting and model-provider settings.
